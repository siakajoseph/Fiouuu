## Ordre de soumission
1. Contrôler le déploiement de la branche SEO : pages, robots.txt, sitemap (12 URL dans le code), HTTPS, accès OAI-SearchBot. Le test web de cette session n'a pas pu accéder au site ; ne pas conclure à une panne générale.
2. Google Search Console : https://search.google.com/search-console — vérifier la propriété DNS, soumettre https://fiouuu.com/sitemap.xml, inspecter les pages déployées. Documentation : https://support.google.com/webmasters/answer/7451001?hl=fr
3. Bing Webmaster Tools : https://www.bing.com/webmasters/ — importer la propriété Google si possible, sinon vérifier, soumettre le sitemap. IndexNow : https://www.bing.com/indexnow/getstarted ; créer une clé, publier la clé sur le domaine et notifier uniquement les URL déployées.
4. Google Business Profile : https://www.google.com/business/ — vérifier l'éligibilité (contact en personne avec les clients), rechercher une fiche existante, ne pas dupliquer. Si activité uniquement en ligne, ne pas créer de fiche. https://support.google.com/business/answer/7039811
5. Bing Places : https://www.bing.com/forbusiness/ — vérifier l'éligibilité puis importer la fiche Google vérifiée si possible. https://www.bing.com/forbusiness/help/syncGoogleBusinessProfile?setlang=en-US
6. Go Africa Online : https://www.goafricaonline.com/inscription — créer ou revendiquer une fiche professionnelle ivoirienne. Vérifier les conditions de publication et les éventuels frais avant acceptation.
7. Sortlist : https://help.sortlist.com/fr/articles/1714404-comment-repertorier-mon-agence-sur-sortlist — créer un profil d'agence gratuit si adapté ; vérifier les options payantes sans les souscrire automatiquement.
8. Clutch : https://clutch.co/get-listed — profil entreprise, avis clients authentiques. https://help.clutch.co/en/knowledge/get-listed-on-clutch
9. LinkedIn : https://www.linkedin.com/help/linkedin/answer/a543852 — créer ou récupérer la page officielle depuis un compte habilité. Ne pas créer de profil personnel fictif.
